# 双机公网联调（POLY × SXBET）

`54.65.44.140` × `52.215.36.68`

> 仅验证 **TCP 9000 镜像 BOOK + HEDGE**；公网 RTT 比 VPC 内网大，**不用于实盘延迟结论**。

## 角色约定（可互换）

| 角色 | 公网 IP | 启动参数 |
|------|---------|----------|
| **POLY** | `54.65.44.140` | `--node=POLY` |
| **SXBET** | `52.215.36.68` | `--node=SXBET` |

两台已探测：**TCP 9000 外网可达**。

## 1. 共享 MySQL

在**同一套库**执行：

```bash
mysql -h <DB_HOST> -u ... -p <库名> < docs/sql/node_route_install_2node_public_test.sql
```

确认：

```sql
SELECT node_code, peer_ip FROM node_config;
SELECT src_node, dst_node, route_json FROM node_route;
```

应仅有 **POLY、SXBET** 两行配置 + **两条** 路由边。

## 2. 安全组 / 防火墙

每台入站 **TCP 9000** 建议仅放行对端：

- A（POLY）：`52.215.36.68/32`
- B（SXBET）：`54.65.44.140/32`

## 3. 部署（v2 分支）

`deploy/.deploy.env`：

```bash
NODE_POLY_HOST=54.65.44.140
NODE_SXBET_HOST=52.215.36.68
```

本机：

```bash
cd deploy
./deploy-service.sh v2 deploy POLY
./deploy-service.sh v2 deploy SXBET
```

远端等价：`--run_bot=true --node=POLY` / `--node=SXBET`。

启动成功飞书：`node-relay-started`。失败：`strategy_entry 未启动(节点配置失败)`。

## 4. 快速验收

1. 两台 **在跑场次一致**（含 SXBET 与 Poly 的 map_key）。
2. SXBET 节点账号 / `api_key` 可用（`canTrade`）。
3. 日志无 `node-route-load-failed`；`ss -lntp | grep 9000`。
4. DryRun 或小仓验证 HEDGE / `arb_id` / `HEDGE_RECV` 落库。

## 5. 回退单机

```bash
./deploy-service.sh v2 deploy ALL   # 或不带第三参，单机 SSH_HOST
# 进程加 --node=ALL
```

## 6. 注意

- 公网镜像 `book_age_ms` 偏大；未实现 `accept_mirror_cidr` 入站校验，靠防火墙。
- 双节点仍可能重复抢同一机会，测试期慎开实盘。
